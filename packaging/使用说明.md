# 译声实时翻译 · Windows x64 候选版

用于观看日语直播：从 Windows 当前播放设备采集声音，在本机识别日语并显示中文字幕。推荐先用默认的本地翻译，不需要 API 密钥或 Ollama。

## 第一次使用

1. 安装后从开始菜单打开「译声实时翻译」。若使用完整的解压目录，请从顶层运行同名 EXE，不要只复制 EXE。
2. 播放直播，在译声点击「开始聆听」。第一次加载模型比之后慢。听不到时，确认设置里选的是**正在播放直播的输出设备**，而非麦克风。
3. 结束时点击停止。历史可回看、导出；关闭时若提示尚未保存，请先取消退出并重试或导出。

安装包不含约 4.25 GB 的 Sakura 翻译大模型。升级时可继续使用已有 GGUF。第一次安装可在设置中下载推荐模型（需要网络与额外空间）、选择自己已有的 GGUF，或直接使用随包提供的「本地 · 轻量翻译」。不想下载大模型时无需改用云服务。

默认本地模式下无需将音频或字幕发给翻译服务；若主动选择在线翻译、在线备用服务，相关文本会发给所选服务。请勿把自己的配置文件、历史库或日志打包转发。模型、后台服务与可用内存、显存和 CPU 均影响速度；不保证所有电脑都能实时。

## 检查与修复

如果提示模型或引擎缺失，请从完整发行文件重新安装或解压，不要单独从不明来源补 DLL。可以在程序目录运行以下命令作离线检查（不录音）：

```powershell
& '.\app\runtime\py312\python.exe' -B -X utf8 '.\app\scripts\launcher.py' --check
```

设置、历史等资料默认独立存在当前用户的 %LOCALAPPDATA%\YishengTranslator\UserData；卸载不应删除该目录。备份个人资料请先退出软件再复制此目录。程序代码许可、第三方组件说明和素材署名分别位于 app/LICENSE、app/THIRD_PARTY_NOTICES.md 和 app/jpsub/assets/backgrounds/credits.json。
