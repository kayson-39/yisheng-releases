# Windows 单文件安装器（构建说明）

这是面向用户的安装项目，不是本机增量补丁。输入是已经按发行白名单构建的 stage。不要把软件安装目录、开发工作区、旧卸载器、用户配置或日志作为 stage。编译器不会递归打包这些位置；构建程序逐项核对新清单和 SHA-256，只将核对过的文件交给 Inno。

目标为 Windows 10/11 x64、当前用户安装、不需要管理员。沿用原 Inno AppId、64 位注册表视图、默认目录与启动器；安装到普通用户 LocalAppData，创建开始菜单及可选桌面快捷方式。检测到同一实例互斥体时会要求先退出程序；无法识别的已有目录、未来版本会拒绝覆盖。项目没有通配删除、清空模型或清空个人目录的操作。安装包明确提供的 ASR/VAD 等必带资源可以通过重装修复；没有列在新清单里的用户模型以及原有 GGUF 不会在升级时被清理或替换。本版不封装翻译 GGUF；安装时可选仅在缺失时下载，或复用已有并经 SHA-256 验证的同名权重。也可跳过，之后在应用内导入。若同名现存文件校验失败，不会自动覆写它。

## 获取编译工具并构建

使用 Python 3.11+ 和已验证来源的原版 Inno Setup 7。旧工程自带完整编译器、简中语言和图标。实际命令行编译器报告版本 7.1.1 以及 `Non-commercial use only`；商业发行前应核实编译器授权。未重新下载任何编译器。切换构建机时需提供完整且可信的工具目录，不要只复制 ISCC.exe。

在工作区根目录运行以下命令。stage 路径替换为净化后的候选目录；输出的上级目录必须存在，末级必须是不存在的新名字。不要在 payload 生成、更新或使用期间并发修改 stage。

```powershell
python packaging/installer_build.py --stage "D:\发布\候选" --check-only
python packaging/installer_build.py --stage "D:\发布\候选" --iscc "D:\工具\inno7\ISCC.exe" --output "D:\发布\单文件构建-001"
```

应当只得到一个 `译声实时翻译安装器-<应用版本>.exe`。本项目关闭 DiskSpanning，不支持以分卷规避大小限制；编译失败、产物为空、超过 2 GiB 减一个字节或出现额外文件时，该输出均不可交付。已经存在的输出不会覆盖。使用可信代码签名证书做最终签名时，应对最终 EXE 重新检查大小、验签并计算交付哈希。

## 还需实机验收的事项

打包输入检查和模拟调用不等价于编译成功、安装成功、数字签名或清洁系统验收。应在一次性普通用户 Windows 10/11 x64 虚拟机，至少验证：全新安装（含中文 Windows 用户名）；第二次安装；从原 Inno 版升级；运行中升级；拒绝降级；桌面快捷方式；旧权重复用/无权重时下载；卸载、重装后设置和历史仍在。用户已导入的模型另做哨兵文件校验。验证静默安装返回码及杀毒软件结果；在副本上验证，不要对开发者当前安装直接跑升级/卸载。安装向导沿用原工程的简体中文语言文件。运行 EXE 时可使用 `/VALIDATE=1 /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="全新的隔离目录"` 验证可解包性；该模式不注册卸载项、不创建快捷方式、不启动译声、不复制或下载 GGUF，不可指向现有目录。它不能替代真正的升级和卸载验收。
