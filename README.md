# 译声实时翻译（Yisheng Live Translator）

一款免费开源的 Windows 实时语音识别与字幕翻译工具，适用于观看日语及全球多语种直播、视频与会议。软件直接从 Windows 当前播放设备采集系统声音，在本机完成语音识别并实时显示翻译字幕——默认全程本地运行，无需 API 密钥，也不上传音频与字幕。

> 当前版本：**0.11.0（全语种版 · Windows x64）** · 许可：MIT

---

## 本次更新重点（v0.11.0）

- **全新支持多语种翻译（全语种版）**：不再局限于单一语种，现已全面支持多语种语音识别与实时翻译，覆盖日语、英语、韩语等多种语言场景。
- **一键切换语种与模型**：保留默认的「日语高速模式」，同时支持在 **「设置 → 语种与模型」** 或主界面 **「模型切换」** 窗口中一键切换全语种识别引擎（SenseVoice / Whisper）与多语种翻译模型。

## 核心功能

- **多语种实时翻译**：支持日语高速模式及多语种实时识别与翻译，按需在「设置 → 语种与模型」或「模型切换」窗口切换识别与翻译模型。
- **系统声音直接采集**：直接听取 Windows 正在播放的直播/视频音频，无需麦克风，也无需额外安装虚拟声卡。
- **离线语音识别**：基于本地离线 ASR 引擎（内置高速模式及 SenseVoice / Whisper 等多语种模型），音频数据不离开本机。
- **灵活的翻译后端**：默认内置「本地 · 轻量翻译」，无需联网、无需密钥即可开箱即用；同时支持本地 GGUF 大模型（如 Sakura、TranslateGemma、Qwen 等）、Ollama 及 OpenAI 兼容 API。
- **悬浮字幕与历史管理**：支持自定义桌面悬浮字幕、历史记录回看、复制与导出 SRT；历史按场次保存，可改名或自定义保存目录。
- **草稿修订与过载保护**：识别结果动态修正时仅补译最新草稿，不覆盖已确认译文；识别与翻译采用有界队列，防止高负载下无限卡顿。

## 第一次使用

1. 安装后从开始菜单（或桌面快捷方式）打开「译声实时翻译」。
2. 播放直播或视频，在译声主界面点击 **「开始聆听」**（首次加载模型会稍慢）。
3. 如需切换非日语语种，点击主界面 **「模型切换」** 或进入 **「设置 → 语种与模型」** 选择对应语种与全语种识别/翻译模型。
4. 听不到声音时，请到设置中确认选中的是**正在播放声音的输出设备**，而非麦克风。
5. 结束时点击停止；关闭软件时若提示尚未保存，请先取消退出并重试保存或导出。

### 关于翻译模型

安装包不含约 4.25 GB 的 Sakura 大模型。第一次使用可以选择：

- 在设置里**下载推荐模型**（需要网络和额外磁盘空间）；
- 指定你**已有的 GGUF** 文件（升级版本时可直接复用）；
- 直接使用随包提供的**「本地 · 轻量翻译」**——无需额外下载即可使用。

## 系统要求

- Windows 10 / 11 x64
- 安装约需 3 GB 可用空间；若下载额外本地大模型需预留对应空间
- 内存建议 8 GB 以上；使用本地大模型翻译时建议配备独立显卡或较强 CPU
- 实时性受所选模型、后台程序、内存与显存影响，不保证所有设备均可零延迟运行

---

## 隐私说明

- **默认本地模式**：音频与字幕均在本机处理，不会发送给任何第三方翻译服务。
- 仅当你**主动选择**在线翻译或在线备用服务时，相关文本才会发送至所选服务。
- 用户配置、历史库、日志默认保存在 `%LOCALAPPDATA%\YishengTranslator\UserData`，与程序目录分离，卸载不会删除。
- 请勿将个人配置文件、历史库或日志打包转发。

### 离线检查与修复

若提示模型或引擎缺失，请从完整发行文件重新安装，不要单独从不明来源补 DLL。可在程序目录运行离线自检（不录音）：

```powershell
& '.\app\runtime\py312\python.exe' -B -X utf8 '.\app\scripts\launcher.py' --check
```

## 源码结构

```
jpsub/
  main.py            程序入口
  core/              识别、翻译、音频采集、分段、导出、历史
    asr.py           本地离线语音识别
    translate.py     翻译调度、流式处理、重试与超时
    local_mt.py      本地轻量翻译
    llama_engine.py  GGUF 本地大模型推理
    audio.py         系统播放设备采集与重采样
    segment.py       断句与草稿修订
  ui/                PySide6 界面（主窗、字幕浮层、模型切换、设置、历史、主题）
packaging/           安装器构建脚本（Inno Setup）与发布文档
tools/               发布打包、验收与自检脚本
tests/               单元与回放测试
```

## 从源码运行

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m jpsub.main
```

需要 Python 3.12。构建安装器见 [`packaging/installer.md`](packaging/installer.md)，版本变更与修复明细见 [`DEVELOPMENT.md`](DEVELOPMENT.md)。
